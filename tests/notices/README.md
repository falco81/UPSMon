# What is to be done by hand (4.5.0)

- `python3 tests/notices/t_engine.py` - the engine on a database of its own
- `bash tests/notices/t_install.sh` - install.sh's helpers
- `node tests/notices/t_ui.js` - the pages of a test instance, run as root beside it
  (writes and removes test files in /etc/upsmon/notices.d)

The format: docs/notices.md.
